# Ruang Belajar — Algoritma dan Pemrograman

Ruang belajar interaktif tujuh pertemuan berdasarkan materi PDF yang ada di direktori ini. Data pelajaran berada di `courseData.js`, antarmuka di `app.js`/`visualizations.js`, dan gaya editorial di `styles.css`.

## Menjalankan lokal

```sh
npm start
```

Buka `http://localhost:4174`. Alternatif tanpa Node server khusus: `python3 -m http.server 4174`.

Progress baca, tema, flashcard, dan jawaban kuis tersimpan di localStorage browser. PDF sumber dikecualikan dari Git dan deployment.

## Isi

- 7 modul: konsep algoritma, logika pemrograman, variabel/tipe data/operator, pseudocode/flowchart, IPO, percabangan, dan percabangan ganda/majemuk.
- Simulasi khas tiap materi: resep algoritmik, computational thinking, variable/operator lab, flowchart interaktif, kalkulator IPO, kondisi if, dan decision tree.
- Pencarian `Ctrl/Cmd + K`, mode ringkasan ujian, progres tersimpan, flashcards, kuis, dan tema gelap.
